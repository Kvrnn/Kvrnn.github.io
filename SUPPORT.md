# Support

Read the project's README, documentation and existing issues first. For reproducible bugs or feature requests, use the affected repository's issue templates when available. For general questions, use its Discussions area if enabled; otherwise follow its README support instructions.

Community help is provided as maintainers are available and does not include a response-time commitment. For paid support or commercial licensing inquiries, contact hello@nightsquawk.tech. A paid software license includes only the support expressly stated in its agreement.

Use SECURITY.md to report suspected vulnerabilities privately. Never post live credentials, personal information, customer data or unredacted diagnostic bundles in public support requests.
